# Skills de diseño del proyecto

Copias de skills de Claude Code para seguir trabajando el diseño "Farol" (ver `DESIGN.md` en la raíz) desde cualquier entorno, incluido Claude Code en la nube. Claude Code las carga automáticamente desde `.claude/skills/`.

| Skill | Para qué se usa aquí | Licencia declarada |
| :--- | :--- | :--- |
| `impeccable` (v4.5.0) | Auditar y pulir la interfaz (`/impeccable audit`, `polish`, etc.). El detector descarga su binario la primera vez que se ejecuta. | Apache 2.0 |
| `emil-design-eng` | Criterio de animación e interacción (filosofía de Emil Kowalski) | No declarada en el archivo |
| `animate` | Construir animaciones nuevas decidiendo si deben existir, curva y duración | No declarada en el archivo |
| `gsap-core` | API base de GSAP, por si alguna animación lo necesita (hoy el sitio no usa GSAP) | MIT |
| `reference-design-contract` | Mantener `DESIGN.md` y `docs/design/` como contrato de diseño | No declarada en el archivo |

Copiadas el 2026-10-04 desde `~/.claude/skills/` de David. No se actualizan solas: si cambia la versión local, hay que volver a copiarlas.
